# Frontispiece - тема для Marinara Engine

[English](README.md) · Русский

![Все стили](previews/all-styles.jpg)

Портрет персонажа стоит на месте, а лента сообщений прокручивается рядом с ним. Внутри три стиля - **Cat**, **Forest**,
**Detective** - и у каждого несколько цветов. Стиль и цвет выбираются в карточке темы.

**Как работает портрет:**
- В групповом чате портреты сменяют друг друга: показывается тот, чью реплику ты сейчас читаешь. Смена мягкая, через
  растворение, и только когда прокрутка остановилась.
- Внизу чата - тот, кто ответил последним; пока пишется ответ - тот, кто его пишет.
- Реплики рассказчика и твоей персоны портрет не меняют.
- Если выключить в карточке темы **Портрет следует за прокруткой**, всегда виден тот, кто ответил последним.
- Если стоит расширение Offstage, портрет меняет и выражение лица: какую эмоцию включишь в Offstage, такой спрайт и покажется.

Нужна Marinara Engine 2.5.0 или новее. Тема проверена на компьютере, iPad и iPhone. Интерфейс маринары английский, поэтому названия кнопок ниже даны так, как они там написаны.

## 1. Установка

Маринара по умолчанию не даёт ставить сторонние расширения. Открыть это нужно один раз.

1. В папке маринары открой файл `.env` и поставь `ENABLE_EXTERNAL_EXTENSIONS=true`. Сохрани, подожди пару секунд.
2. **Settings** (шестерёнка вверху) → вкладка **Advanced** → блок **Danger Zone** → включи **Allow third-party extension imports**
   → **I Understand, Enable**.
3. **Settings** → **Addons** → **External Extensions** → **Import Extension File** → выбери `Frontispiece-1.0.0.personal-extension.zip` (раздел **Releases** справа на этой странице).
4. У темы в списке нажми кнопку питания слева (**Review and run**) → **Run Exact Code**.
5. Обнови страницу. Вверху появится кнопка темы (палитра) - в ней стиль, цвета и настройки.

На телефоне **Settings**, **Characters** и **Personas** лежат в меню **More** (кнопка справа вверху).

## 2. Настройки маринары, на которые рассчитана тема

**Settings** → **Appearance** → кнопка **Roleplay** → блок **Roleplay Presentation**:
- **Chat position** - **Center** (стоит так по умолчанию). Слева или справа тема оставляет только плашки, без портрета.
- **Scrollable Avatars** - включить. Без этого ломается картинка персоны.
- **Roleplay Avatars** - **Glued Side Panel**. Тема сделана под этот вид; другие работают, но хуже.

**Settings** → **Appearance** → кнопка **Conversation** → **Chat Layout** - **Linear**. С **Bubbles** тема режим переписки не оформляет.

Групповой чат: круглая кнопка **Chat Settings** в чате → **Group Chat** → **Mode** - **Individual** (по одному
говорящему в сообщении). Иначе портрет не меняется.

Время у сообщений: **Settings** → **Advanced** → **Message Tools** → **Show message timestamps**. Тема показывает время, только
если это включено.

## 3. Портреты

Тема показывает спрайты персонажа - картинку, которая подходит к сцене.

**Какая нужна картинка** (персонаж и персона):
- вертикальная, примерно **2:3** (хорошо - около 1365 × 2048);
- лучше **PNG с прозрачным фоном**;
- фигура **до пояса или ниже**, голова в верхней трети, над ней немного воздуха.

В архиве с примерами есть `avatar-template.png` - прозрачный шаблон 2:3. Положи его поверх своей картинки, чтобы проверить
кадр.

**Спрайты**: **Characters** → персонаж → вкладка **Sprites** → **Facial Expressions**. Впиши имя (`neutral` - обычное
лицо) → **Upload** → выбери файл. Можно сразу папку: **Upload Folder**, имя файла станет именем эмоции (`neutral.png`,
`anger.png`, `shy.png`…). Эмоцию выбирает расширение Offstage, если оно стоит; без него тема показывает `neutral`. Если
спрайтов нет совсем, тема покажет аватар персонажа.

Имена эмоций, которые понимает Offstage: `anger`, `sadness`, `anxiety`, `fear`, `shy`, `tender`, `love`, `desire`,
`playful`, `fun`, `cold`, `suspicion`, `jealousy`, `hurt`, `guilt`, `cruel` и `neutral`. Спрайт с другим именем тема не
подхватит.

**Квадрат лица**: **Characters** → персонаж → **Metadata** → **Avatar** → **Avatar Crop**. Поставь квадрат вокруг головы и
нажми **Save**. По нему рисуются круглые аватарки (телефон, iPad, режим переписки, список чатов), а на компьютере - карточка
персоны. Для персоны так же: **Personas** → персона → **Metadata** → **Avatar Crop**. Квадрат ставь после загрузки аватара:
новый аватар его сбрасывает.

## 4. Примеры из релиза

В архиве `Frontispiece-examples.zip` (там же, в **Releases**):
- `characters` - героини из превью (Cat, Forest, Detective и Detective в цветах Noir);
- `personas` - персонажи игрока к ним;
- `backgrounds` - фоны комнат;
- `avatar-template.png` - шаблон кадра.

Как собрать сцену, как на превью:
1. **Characters** → новый персонаж → **Metadata** → **Upload avatar** - картинка из `characters`. Ту же картинку загрузи на
   вкладке **Sprites** под именем `neutral`. Поставь квадрат лица.
2. **Personas** → новая персона → **Upload avatar** - картинка из `personas`, квадрат лица.
3. Открой чат → **Settings** → **Appearance** → **App** → **Backgrounds** → **Chat Background** → **Browse library** →
   **Import Backgrounds** → картинка из `backgrounds`.
4. В карточке темы выключи **Фон по умолчанию** (иначе тема рисует однотонный фон своего цвета, а не картинку чата).

## 5. Настройки темы

Кнопка темы вверху (палитра):
- **Стиль** - Cat, Forest или Detective; **Цвета** - варианты выбранного стиля. Каждый стиль помнит свой последний цвет.
- **Портрет следует за прокруткой** - портрет показывает того, кого ты сейчас читаешь. Выключено - того, кто ответил последним.
- **Мой шрифт маринары в репликах** - текст сообщений твоим шрифтом из настроек маринары.
- **Фон по умолчанию** - однотонный фон темы. Выключено - фон чата.
- **Реплики персонажа цвета моих** - плашки персонажа того же цвета, что твои.
- **Мои цвета маринары** - все цвета берутся из настроек маринары.
- **Убрать кота / Убрать булавку** - без талисмана на последней реплике (Cat и Detective).
- **Убрать портрет из шапки** - только Forest, только телефон: простая полоса кнопок вместо головы персонажа.

Настройки хранятся в каждом браузере отдельно: на телефоне и компьютере их выбирают отдельно.
